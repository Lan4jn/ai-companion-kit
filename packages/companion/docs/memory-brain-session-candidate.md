# 记忆会话授权候选（未部署）

`src/memory-brain-session-candidate.js` 提供可信本机生命周期管理器的进程内能力：仅独占创建全新目录；固定完整作用域和来源；正常连续运行期间授权读写；连续性检查失败、抛错或目录身份变化后永久关闭该能力。调用者可 `close()`。它不是聊天消息可授予的权限，也没有接入生产聊天入口。许可未核实，继续关闭生产功能。

## 正常聊天接线阻塞条件

- `isTrustedMemoryMessage` 只证明对象由本进程 OneBot 解析且关键字段未修改；WebSocket 事件本身未证明来自经认证、不可伪造的 QQ 传输端点。`user_id`、`message_id` 或配置的 owner ID 只是声明值，不能充当身份认证。接线前必须建立并审计端点身份、传输完整性、发送者身份绑定和连接失效/重连后的撤权机制。
- 独占创建及目录 inode 检查不能检测向原目录内覆盖恢复旧数据库。`continuity` 是调用方提供的断言，并非独立权威。`test/memory-brain-inplace-restore-diagnostic.test.js` 用合成数据证明：同一会话内先备份、撤销，再原位恢复备份，旧记忆仍能召回。接线前必须有独立于数据与备份恢复域的可信撤销/遗忘和版本权威，能识别原位替换、回滚和中断竞争；任一不确定状态都拒绝读取。单靠目录 inode、进程内布尔值或调用者声称连续安全均不足够。
- 授权链还须在真实聊天入口绑定上述两个可信事实、严格限定单条消息和作用域、关闭时撤销并隔离并发操作，再以合成数据验证；当前没有满足这些前提的可用接线，因此继续默认拒绝召回，不修改生产配置。


调用者必须控制父目录和整个生命周期，并在恢复、维护、替换、并发写入或状态不确定之前停止所有操作、撤销能力，且在读写期间确保不存在这些操作。`continuity` 必须由此可信管理器基于独立可信状态给出；恒真回调不是恢复检测。目录 inode 检查只是有限防护，无法检测原目录内文件替换、在检查后发生的恢复、整个目录回滚或同权限进程恶意操作。回调和文件检查之间有竞态；此候选不提供跨进程排他、独立防回滚账本或重启后连续性证明，不能用于无外部保障的生产。已有目录、重启或恢复均不能通过首次初始化重新授权；需要独立可信账本和可信恢复流程，无法核实时拒绝，人工恢复仍依照 recovery-candidate 文档进行。正常聊天接线和安全的重启后授权仍未完成，不能宣称端到端可用。

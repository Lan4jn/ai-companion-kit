# 抖音兴趣记忆：捕获适配器安全边界（未启用）

`observeDouyinInterestCandidate` 是关闭的适配器入口，任何输入均拒绝；不调用播放器、模型、持久化或召回。`evaluateOfflineDouyinInterest` 仅用于合成数据形状实验，不提供来源或授权证明。没有配置项可以打开此入口。

现有 `perceiveDouyinFullPage` 将页内 `_ROUTER_DATA` 与视频 URL 对照，并用页内 JavaScript 监听播放器进度，再对 URL 发起独立 fetch。它能提供有价值的播放观察，但网页可控制元数据和执行环境；被 fetch 的内容与播放器实际解码的字节没有可信的绑定，入口也接受调用者传入的 page。其返回对象和模型描述都可由调用者伪造，不能作为真实来源、原始内容或观看的不可伪造证据。相关页面观测既不认证主人，也不授权保存或召回。

开放前至少需要：可信隔离捕获器独立绑定认证来源、作品 ID、实际解码的原始媒体与连续播放证据（含会话和有效期）；证据须由捕获器保护且消费端验证完整性、防篡改和重放；处理内容由可信通道取自该证据而非模型自报。另需独立的、可撤销且限定范围的主人授权，分别控制采集、模型处理、私密持久化及召回；存储需隔离主体、加密及权限保护，并定义撤权删除和竞态处理。验证这些边界后才可讨论接入，不能通过添加布尔开关、调用方提供回调或复制 `complete` 标志绕过。

当前无真实账号、设备或生产接入，也不保存媒体或候选内容。合成测试不证明真实站点真实性、隔离性或授权能力。

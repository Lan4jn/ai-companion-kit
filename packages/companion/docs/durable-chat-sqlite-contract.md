# 持久聊天历史安全契约

默认关闭。仅为经过固定证书认证的 OneBot 主人私聊启用；必须明确授权本地角色卡和与主人私聊完全匹配的 managed memory-brain scope，并授权 `qq-private-message`。数据库和 journal 仅允许受信任本地进程访问；本地运维者和 OneBot 上游身份声明属于信任边界。

聊天历史以 OneBot 消息 ID 作遗忘凭据；消息 ID 必须为规范整数。同一 scope 内应使用稳定的消息 ID 命名空间，切换账号或重置消息 ID 之前必须人工迁移和审查，避免碰撞。网络操作的 unknown 不自动重试；逐段离线核实后使用原有人工对账入口授权继续。历史提交失败不删除已确认回执，后续可幂等补记；已遗忘凭据的补记不恢复内容。

数据库或 journal 的整体回滚不能由本地标记检测；恢复备份前须停止全部读写和发送，人工核对所有遗忘、撤销、消息凭据和发送结果，确认后才恢复服务。未经核实不要通过重启代替对账。遗忘是逻辑删除，不保证 SQLite 文件、WAL、备份或日志中内容的物理擦除。

# Configurable egress candidate (not enabled)

`src/douyin-configurable-egress-candidate.js` is a standalone request primitive, not a proxy listener, browser sandbox, or production integration. Defaults contain no hosts or routes and deny all requests. No official hosts or paths are assumed: a trusted operator must independently inventory and review the exact official HTTPS host, method and path tuples before any future use. Exact path rules are deliberately stricter than a host-only allowlist; host-level policy cannot distinguish an authorized login from other same-domain APIs, uploads, open redirects, or exfiltration. Query strings, headers, request contents and responses also need application-specific review; exact path authorization alone is not a complete data-loss policy. A POST rule permits up to 4096 bytes to that exact host/path and must not be added casually.

Each hop requires authorization and fresh DNS validation of every answer, followed by a pinned connection with hostname SNI and certificate verification. Redirects are bounded, same-host only, individually authorized, reject ambiguous raw paths, and do not replay POST. Requests/responses, headers and total time are bounded. Only HTTP(S) request semantics in this primitive are implemented; raw sockets, CONNECT, WebSocket, UDP/QUIC, service workers and other processes are NOT contained by this module. A separate enforced OS network boundary and a request-aware authenticated broker must deny those channels; Playwright routing or an opaque CONNECT tunnel alone is insufficient. This candidate is not wired into the existing broker or login gate, and does not make real login ready.

`lookup`, `port`, and `ca` request options are trusted test/operator inputs and MUST NEVER be accepted from a browser, untrusted IPC message, environment supplied by the sandboxed worker, or other untrusted client. DNS validation and pinning cannot account for privileged local route manipulation, transparent proxies, or NAT; the production host's network routing and trust store must also be controlled. No real account or site was contacted in the synthetic test.

Offline regression: in an isolated network namespace only, bring loopback up and bind synthetic address `8.8.8.8/32` to it, then run `DOUYIN_TEST_NETNS=1 node --test test/douyin-configurable-egress-candidate.test.js`. Never bind that address on the host network namespace. The temporary self-signed certificate and injected resolver are synthetic only.

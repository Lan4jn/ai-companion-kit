# 本机聊天恢复

仅运行服务的系统用户或 root 可访问恢复入口；不通过网页、群聊或网络操作。服务运行中执行：

```sh
node scripts/chat-recovery.mjs
```

列表显示本进程内稳定的随机密钥会话指纹和该回合开始处理的 UTC 时间（不是已发送时间），不显示会话身份或消息正文；指纹在进程重启后改变。它只能区分会话，不能反推出身份：如果仅凭时间和外部记录无法唯一确认目标，请取消操作，不要猜测。核实外部事实后，选择 `delivered`（已处理）或 `discard`（丢弃该未知回合），并输入 `YES`；两者均跳过该回合，之后按顺序处理该会话的其他回合，绝不重试未知回合。提示“已接受恢复”不代表后续消息已投递，后续可能再次暂停。不同会话互不恢复。请勿把指纹、时间或终端记录发到聊天或日志。

入口在 `/run/companion-chat-recovery-<运行UID>/control.sock`，目录权限 0700；正常停机会清理。异常退出后可能遗留目录导致入口拒绝启动：先确认对应服务已完全停止，再由运行用户或 root 检查并手动清理该目录，不能跟随符号链接或删除其他文件。重启会丢失内存中的待处理状态，不能用重启代替恢复。入口启动失败时聊天仍按原安全策略暂停。

代码变更不会自动部署到现有进程；在获得授权并完成部署之前，当前服务不可使用此入口。

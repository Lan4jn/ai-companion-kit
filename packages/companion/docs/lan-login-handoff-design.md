# 局域网本人接管：设计与当前限制

**尚不可用于真实账号。** `scripts/synthetic_lan_relay.py` 只是强制回环地址的合成 WebSocket→Unix 流实验，没有提供网页、noVNC、真实浏览器、账号导入或局域网监听。不要把它接至真实浏览器、无认证的 18888 面板或反向代理。`synthetic_lan_relay_test.py` 使用内存中的合成字节回显；已有 `isolated_login_prototype_test.py` 单独测试隔离 Xvnc 与合成 Chromium 页面；两项目前没有串起来，不是局域网或真实登录端到端证明。

## 可行架构（待实现）

* 独立临时监听器只绑定本人指定的局域网 IP，依据实际 socket 源地址限制到明确网段（而非信任转发头）；不复用目前无认证 18888 服务，也不得将未经验证的画面或控制接口挂到其上。防火墙和绑定需要现场复核，不能用 Host / IP 当身份认证。明文 HTTP 容易被同网窃听、篡改或冒充，密码、短信码、cookie、一次性凭证和画面均可能泄漏；仅适合本人控制、可信的私有局域网，不适合公共、共享或不可信网络，无法保障抵抗网络旁观或中间人。
* 通过现场线下渠道由本人向服务输入高熵一次性配对凭证，绑定平台、会话、操作权限与到期时间；不要经聊天、URL 查询串、访问日志、shell 命令参数或持久存储传递凭证。具体验证与分发机制、密钥展示方式、重放和竞争保护仍需设计和验证。强随机凭证可降低其他普通 LAN 客户端的未授权操作，无法防止在明文网络上窃听并抢先使用凭证的攻击者。
* 单独非特权 UID/沙箱创建保留浏览器沙箱的临时桌面和官方浏览器会话，禁止其他 agent、截图器、远程观察器及同 UID 进程访问；关停自动脚本以及截图、输入、网络和浏览器跟踪记录，验证 root/宿主权限仍可观察，无法对其承诺隔离。认证 WebSocket 限制单个消费者并以私有 Unix socket 代理桌面，禁止旁路；断线、取消、过期、进程崩溃立即撤销及清理。真实实现需独立监督器和重启后清理。
* 需要接管**触发验证的原始会话**：现有 `src/douyin-qr-daemon.js` 明确以 `headless: true` 启动，无法直接把该已启动浏览器变为有头桌面；登录开始时就需在可接管的隔离桌面创建同一 Playwright 浏览器，才可能在挑战出现时移交。改造之前触发的旧会话无法通过新建窗口接续挑战。当前贴吧来源 `src/tieba-playwright.js` 是无登录、只读、匿名浏览器，不存在可交接登录会话；需要单独实现贴吧登录和消费路径。抖音现有代码还有截图和轮询观察逻辑，必须先在接管全过程禁止并验证。
* 本人直接操作官方页面和完成验证码/风控；独立验证成功再考虑由经明确授权的专用组件安全移交必要凭据或维持同一进程会话，验证消费者兼容性和失败回滚。未经独立平台验证不得宣称登录成功，不可把本人点击或 cookie 存在当成成功。

## 已运行的测试

`python3 -m unittest discover -s test -p 'synthetic*test.py' -v`：15 项通过，覆盖合成单次授权、错误令牌、来源、重放、超时、写入及无明文请求头日志等。`python3 -m unittest discover -s test -p 'isolated_login_prototype_test.py' -v`：3 项通过，覆盖独立的合成 RFB 指针、清理和窗口标题判断。没有实际用户操作或真实平台交互。生产账号接入前仍需组合真实浏览器会话的端到端测试、安全评审及现场部署验证。

# 持久聊天历史依赖最小化（隔离候选，未部署）

新生成的批次将可信主入口取得并冻结的历史快照，转换为带版本、目的地及域隔离的 HMAC 承诺列表；输出签名继续绑定该列表，进度和回执继续绑定输出签名。发送前在原有跨进程遗忘锁内读取真实 SQLite 和其他后端 tombstone、重算承诺并检查每个原依赖仍存在，锁贯穿发送及回执处理。生成期间遗忘会阻止发送；unknown 不自动重发。新指纹和旧 history 数组均不能经不带遗忘锁的通用恢复发送路径发送；主入口对旧数组或缺少指纹 fail closed，不修改、不清除、不重签旧日志。

仅可信主入口的 `createLocalDurableBrainGenerator` 绑定真实模型输入；通用注入的生成器本身是受信任的权威，不能把不可信回调作为来源证明。HMAC 不隐藏依赖数量和相等性，持钥者可猜测低熵正文；它不移除模型输出或当前输入中复述的历史，也不清除历史 SQLite、WAL、备份或旧加密日志。旧日志仍可用共享密钥解密，需另行设计处理，不承诺物理擦除。依赖必须依靠全部遗忘写入方遵守同一锁；同 UID 恶意代码、持钥者、未经协调的 SQLite 写入及整体回滚不受此机制防护。当前读取最近 20 条，老依赖落出窗口时保守阻止发送。

历史格式的无历史字段旧通用候选仍存在独立的手动可信恢复能力，不能将其用于主入口遗忘安全恢复；本次没有改变或重签其旧格式。是否能统一禁用该独立恢复通道需要单独审计部署和兼容性，不能将整个旧生态宣称已 fail-closed。新格式仅隔离测试，禁止部署。

# 抖音自然续期（默认关闭）

仅在确认所有使用同一数据目录的旧版本小鱼、登录辅助脚本及其他写入者已经退出，并确认所有写入/删除均使用 `createCredentialStore` 后，才可在新进程中设置 `DOUYIN_NATURAL_RENEWAL=1`。不要在旧进程仍运行时开启；CAS 无法阻止不遵守锁协议的旧进程在提交后覆盖文件。禁用时不创建续期快照，不做身份校验或续期写入。

指定视频、推荐流和主人主页的成功浏览会尝试从浏览器内存提取候选 Cookie；分别用独立上下文读取原凭据和候选凭据的本人资料，仅双方成功且非空 `sec_uid` 一致时以快照版本 CAS 原子写入。风险、网络错误、身份不确定、凭据无变化或并发冲突均不写。快照、提交与删除依靠目录锁协调；崩溃后遗留锁需要确认持有者确已退出再由管理员人工处理。外部手工删除或覆盖不遵守该协议，无法保证竞争安全；登出应通过 store 的 `remove(version)`。

校验请求可能被抖音风控、拒绝，或者旧凭据在浏览期间已失效，因此此功能不能保证平台自然续期。测试使用合成 Cookie 和假身份校验，不代表真实账号或线上平台兼容性。启用前应先安排旧进程退出、审计外部工具并获得用户授权；不要记录 Cookie、资料或身份标识。

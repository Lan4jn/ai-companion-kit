# 抖音网页登录隔离：候选边界及生产阻断项

状态：禁止真实登录；现有生产工厂无条件拒绝启动。此文不是部署指令或生产安全证明。

## 信任分层

- 房间服务不持特权、不选择可执行文件、rootfs、UID、路由或出口策略。独立最小特权监督器是唯一配置权威，通过受限 Unix socket、对端凭据及不可伪造的请求身份授权；严格限制会话数和寿命。不要将客户端提供的命令/路径变成特权执行。
- 管理员事先跨 NSS、subuid/subgid 和全部分配器独占 UID/GID；具备持久、原子、防回滚的分配账本与崩溃恢复。每会话唯一且不复用身份；耗尽或账本不一致关闭。shadow 本地账户方案不是全局 UID 保留。
- 可信 rootfs 由管理员离线构建和签名，验证完整内容及供应链、只读挂载并以可信目录 fd/内核约束避免检查后替换；包括动态库、浏览器、字体、配置及所有祖先，不仅检查 node 和 chromium。禁止 worker 改动 rootfs；更新通过独立审计。
- 每次启动独立 mount、PID、network、IPC 命名空间，非 root worker，禁止额外 capabilities、no_new_privs、受审 seccomp 和资源 cgroup（内存、进程、CPU、文件数）；私有 tmp、dev、display、profile，禁止宿主文件、设备、网络及同 UID 互访。PID 1 持独立生命周期管道、父进程死亡后终止所有子孙；由可信宿主管理者回收，使用目录 fd 和 inode 防替换，模糊情况不删并告警。
- 唯一出口为独立可信 broker，通过继承 FD 接收请求；由 broker 而非浏览器实施精确的官方 HTTPS 域名、方法、路径、DNS 公网地址验证、固定连接和证书校验，拒绝重定向/私网混合解析/未经许可的 WebSocket；风险响应或验证码交由本人在同一官方会话操作，不绕过平台控制。未有审核过的兼容策略前默认全拒绝。
- 房间仅绑定获批准 LAN、不暴露公网；校验 Host、Origin 和 Fetch Metadata；会话专属授权、限制并发与速率，防止跨会话访问，断连、撤销、超时和崩溃均撤销和清理。挑战屏幕及二维码视作敏感信息，不记录验证码、cookie 或个人身份。

## 本次实际范围与缺口

候选 broker 加入 socket 数和进行中请求上限，并从接收首个报头数据起限制报头耗时；仍不是完整 HTTP 解析防护：同一个数据块内完整请求后紧跟不完整下一报头、之后不再发送字节的流水线边界尚未可靠计时；需要协议级严格禁止流水线或可证明的逐请求报头计时，包含分片、合包与空闲后重用测试。单流过载当前销毁整个连接，需与交互可用性一起验证。上游并发及背压的对抗测试未完成。

生产接管还需实现并审计上述特权监督器与可验证 rootfs、UID 分配协议和销毁；使用真实 viewer/Chromium 与独立 broker 在隔离环境完成跨 UID 攻击、宿主读写/信号/网络否定、并发与崩溃清理、资源耗尽和 LAN 内外访问测试；验证真实设备输入、官方站点策略兼容和验证码体验；核查凭据迁移及所有旧写入者退出；部署和回滚方案、人工安全审查批准。任一项缺失维持关闭。合成测试不能证明真实站点兼容或平台授权。

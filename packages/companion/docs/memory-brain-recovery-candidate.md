# 记忆恢复的保守授权（候选，默认关闭）

> 历史候选说明；当前受控恢复及正常使用契约见 [运维信任契约](memory-brain-trust-contract.md)。生产仍默认关闭。

许可证和来源尚未明确，保持功能关闭，不部署。整个目录都可回滚，程序无法区分备份与原件；同权限文件、撤销标记、时间戳都不是防回滚权威。因此适配器默认拒绝所有召回及候选排序，包括正常启动；普通聊天接线不提供恢复授权，失败后走原有回忆逻辑。写入及撤销等管理操作仍受原有授权控制。该门禁并不能阻止拥有同账户权限的人直接读取数据库或改代码。

需要查看备份时，受信任的本机管理员先在隔离环境核对备份之后所有撤销和遗忘，确认其允许恢复范围，再在私密、经认证的交互式终端运行 `node scripts/memory-brain-recovery.mjs`，输入绝对目录、完整作用域、来源和查询，并明确输入 `AUTHORIZE RESTORED MEMORY`。仅该进程和一次查询获得授权，不生成永久授权文件；结果显示在终端。TTY 本身不是身份验证，勿通过网络或共享终端暴露。无法核对历史时不要授权。若需要重新启用自动召回，须另行设计可靠的独立授权及生命周期，不能仅把回调接成恒真。

如需重建，先保持应用停止访问该存储，可信管理员从可信的外部记录逐一对所有受影响作用域及来源完整重做撤销，再核对结果；缺少完整记录则无法证明安全，仍须拒绝召回。当前没有自动重建实现，也没有声称能检测正在运行时整个目录回滚；即使一次性查看授权，也不应在授权期间并发恢复目录。

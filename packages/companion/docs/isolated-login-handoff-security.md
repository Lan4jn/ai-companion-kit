# 本人登录交接：安全边界与阻碍

**当前不可用于真实账号。** `isolated-login-prototype.py` 运行断网合成页面并将该页面的可信指针事件模拟交给 `synthetic_login_handoff.py`；后者只接受固定合成字节，未接入任何真实平台。该链路不是生产登录交接。不要把它连到现有无认证 HTTP 面板，也不要用当前 root 浏览器加载真实账号。

## 生产部署必须先实现并验证

1. 管理面必须有单独的强身份认证和会话授权、CSRF/Origin 防护与审计（不记录屏幕、输入、cookie、令牌），身份绑定到授权本人。不得以网络来源或 Host 代替认证。所有控制接口拒绝未认证请求。
2. 每次登录创建短时、随机、一次性会话；以独立非特权 UID、受限容器/沙箱和干净临时浏览器资料启动官方站点，禁止访问已有资料、宿主机密钥、容器套接字与服务凭据；限制网络目的地和出站能力（包括浏览器页面可能跳转的非平台域名）；浏览器必须启用沙箱，不使用 `--no-sandbox`。限制 CPU、内存、进程、磁盘。按平台域名白名单精心设计，不应阻断官方验证码及登录域名；跳转和 DNS 重绑定风险需具体测试。
3. 仅本人经认证的私密通道观看和操作 GUI，服务端不提供截图/按键给 agent，不记录图像或输入。可用受严格权限保护的 Unix RFB socket 通过验证服务器主机密钥的 SSH 通道供本人连接；需验证同 UID/root、其他客户端、重连、并发、隧道终止后的访问风险。`SecurityTypes None` 仅能用于受隔离的私有 socket，绝不能暴露 TCP 或依赖用户不知情的公网端口。独立 UID/socket 和受控代理必须实际限制谁能连接，不能只依赖 socket 文件模式。
4. 本人从官方页面开始并直接完成包括密码、验证码、挑战在内的所有步骤。agent 不读取或输入；不自动绕过挑战。本人明确批准一次交接，不可把普通页面按钮或未认证 API 布尔值当授权。授权应绑定平台、具体会话、过期时间和预期用途；取消、拒绝、断连、超时、进程退出或重启默认撤销。
5. 在隔离环境通过平台官方可验证的登录状态进行独立验证，失败、风险、网络异常均不可判为成功；平台接口和允许的凭据形态须分别确认。避免日志暴露账户身份、cookie 或响应。导出只限必要的平台允许数据；消费者需要明确支持该格式，浏览器加密 cookie、设备绑定和过期均可能导致跨进程复制无效。不可假定迁移 cookie 就能复用登录。
6. 交接由受权限限制的专用 broker 执行，agent 不接触明文；授权和验证都成功后才写入预先检查的私有目录，同目录临时文件 `0600`、flush/fsync、原子 rename、目录 fsync；避免符号链接、目录替换、并发和路径穿越。原子替换与消费者同步、崩溃恢复及失败回滚均需端到端验证。数据在 broker/消费者间使用 OS 隔离或密钥管理，严禁经无认证 HTTP 或日志传递。
7. 强制 TTL 由独立监督进程保证，超时及各异常路径杀死整个进程组、撤销通道、清除临时资料；崩溃或主机重启后扫描并回收。删除不等于介质安全擦除，优先使用加密的临时存储并销毁密钥。验证进程、socket、资料、监听器均消失。
8. 合成服务端到端测试须覆盖本人授权、平台验证、错误身份、重放、竞争、限时、断线、取消、重启、写入失败与泄露检查；再以平台许可的测试账号、本人亲自完成页面流程验证。合成测试和真实用户/平台验证不能互相冒充。

## 目前验证范围

合成端到端测试通过私有 Unix RFB socket 发出模拟指针事件，在同一断网浏览器页面变色后，检查固定合成文件原子写入和清理；单元测试另覆盖一次性令牌、拒绝、时限、并发、符号链接和写入失败。页面将随机标记写入 X11 窗口标题，进程用 `xwininfo` 读取标记后模拟授权和平台验证；这不是安全凭证或本人身份认证，任何能控制 X11/RFB 的主体均可能伪造。浏览器 `isTrusted` 不等于真人。原型超时后不导入，但当前无独立超时监督、断线撤销、抗 X11 伪造或真实平台验证。临时目录连同合成文件在退出时清除，不会导入生产消费者。实现上述各项并经安全评审前，不应开启真实登录或凭据导入。

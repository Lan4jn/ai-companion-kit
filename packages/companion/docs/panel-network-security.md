# 控制面板网络安全

`node scripts/panel.mjs [端口]` 是独立面板，没有身份认证，只监听 `127.0.0.1`。通过 SSH 隧道等受保护的方式访问，不要用未经认证的反向代理将它暴露到网络。

虚拟居室内嵌的 `/panel` 由居室的监听配置控制，不受独立进程监听地址更改的影响。若居室允许局域网访问，局域网用户可能无需身份认证即可访问面板及其敏感数据和操作；来源检查和防火墙不是用户身份认证。请将其限制在可信设备和网络，按需使用经过认证的安全访问方式。此修改不声称解决全部安全风险。

已经运行的独立面板不会因修改文件自动切换监听地址，需要在合适时机由管理员单独重启该独立进程；无需为此重启虚拟居室或其他服务。
